VPN Settings
HTTP Custom Config (PWA)
🛡️
ไม่ได้เชื่อมต่อ VPN
พร้อมเชื่อมต่อไปยังเซิร์ฟเวอร์
📁 โปรไฟล์การตั้งค่า (ไม่ต้องใช้ไฟล์ .ini)
ข้อมูลทั้งหมดจะถูกบันทึกในแอปและเบราว์เซอร์อัตโนมัติ
🔀 โหมดการเชื่อมต่อ (connection_mode)
เลือกรูปแบบการเชื่อมต่อ VPN ให้ตรงกับการใช้งาน
โหมด 0
SSH Direct
เชื่อมต่อ SSH โดยตรง ไม่ใช้ Payload หรือ SNI
โหมด 1
HTTP Payload
ส่ง Custom Headers พร้อม Squid หรือ Remote Proxy
โหมด 2
SSL / TLS (SNI)
Handshake ผ่าน SNI Host เช่น fast.com, line.me
โหมด 3
Payload + SNI
ผสานทั้ง HTTP Headers และ SSL SNI พร้อมกัน
แทนที่แท็กอัตโนมัติ (auto_replace)
แปลง [host], [port], [crlf] เป็นค่าจริง
🖥️ เซิร์ฟเวอร์ SSH ([ssh])
บีบอัดข้อมูล SSH (enable_compression)
เปิดใช้งานคำสั่ง -C เพื่อประหยัดเน็ต
🌐 เพย์โหลด & พร็อกซี ([Payload])
ปรับแต่ง HTTP Custom Headers
[crlf] [crlf*2] [host] [port] [host_port] [ua] [protocol] [split] [delay_split]
🔒 Server Name Indication ([sni])
ใช้สำหรับโหมด 2 (SSL) และโหมด 3 (Payload+SNI)
⚡ พรีวิวเพย์โหลดจริง (Live Formatted)
ข้อความที่ injector จะส่งไปยังเซิร์ฟเวอร์จริง
📄 โครงสร้าง settings.ini เสมือน
สำหรับคัดลอกไปรันบน VPS / runvpn.sh
📥 นำเข้าการตั้งค่าจาก settings.ini
วางเนื้อหาไฟล์ .ini เพื่อแปลงเป็นโปรไฟล์ในแอป
📱 ติดตั้งเป็นแอป PWA
คุณสามารถติดตั้งเว็บนี้ลงหน้าจอมือถือ หรือนำ URL ไปแปลงเป็น APK ผ่าน PWABuilder.com ได้
